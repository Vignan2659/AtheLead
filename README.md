# AtheLead

AtheLead is a bridge between rural athletes in India and the sports board that selects Olympians, built towards the 2036 Olympic Games in India. This MVP shows one Olympic sport, athletics, end to end.

- **Athletes:** daily check-in, training, diet plan, progress, and a verified athlete passport.
- **Coaches:** track every athlete, with men's and women's sections analysed separately, and change plans based on progress.
- **Board:** see the pathway funnel, the rural share, a talent map of India and village talent, then select on verified data.
- **Guardians and district officers:** consent for minors, talent flags and trial invitations (Tamil Nadu pilot).

The Sports SLM suggests and people decide. All data in this MVP is fictional demo data for the Velora Sports Union.

## Run it

```bash
npm install
npm run dev
```
